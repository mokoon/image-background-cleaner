# image-background-cleaner
누끼 따기 프로그램


bat 실행시 7860 포트 열고 웹으로 127.0.0.1:7860 실행됨

기본 설정 다크모드 설정에서 변경가능

rembg랑 alpha matting 결과값이 나오고

결과창 아래에 있는 이미지 편집기에서 각 이미지와 원본 이미지가 원본,rembg,alpha matting 순으로 레이어로 구성되어 있고 원본 이미지는 기본 투명도 0 설정되어있음

이미지 편집 도구로 수정 가능 단축키는 되돌리기(ctrl+z) 선택영역 제거(delete)만 구현되어있음

편집 도구 아래 있는 테두리 강조는 이미지의 투명도를 보고 임계값에 따라 배경과 이미지간의 테두리를 설정하고

설정된 테두리에 사용자가 크롭한 이미지가 강조될 수 있도록 원하는 테두리를 만들 수 있는 기능

레이어 편집기에서 이미지를 가져온 경우 세션에 원본 이미지가 남아있기 때문에 크롭한 이미지 아래 레이어에 원본 이미지를 넣어 이미지 강조 연출을 하기 용이하게 구현됨
