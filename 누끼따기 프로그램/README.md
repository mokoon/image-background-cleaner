# 캐릭터 배경 분리 비교 (char-cutout)

이미지 1장을 올리면 2가지 방식으로 배경을 제거해 투명 PNG 결과를 나란히 비교/다운로드하고, 레이어 편집기에서 부분별로 골라 합칠 수 있는 Gradio 앱.

| 방식 | 내용 | 특징 |
|---|---|---|
| A. rembg | `isnet-anime`(기본) / `u2net` 딥러닝 모델 | 배경색 무관, 애니 캐릭터에 강함 |
| B. 알파 매팅 | isnet-anime 마스크로 trimap 생성 → pymatting closed-form 매팅. 경계 폭: `경계 강함 (5px)` / `경계 중간 (10px)` / `경계 약함 (20px)` / `사용자 설정`(슬라이더 2~30px). 라벨 옆 `?`에 마우스를 올리면 설명 표시 | 머리카락 등 반투명 경계가 부드러움, 경계 폭이 넓거나 큰 이미지일수록 느림 |
| 레이어 편집기 | A와 B를 겹친 두 레이어로 두고, 선택한 레이어를 지우개/복원 브러시로 편집. 레이어 순서 버튼으로 즉시 전환(기본: A가 위). 레이어별 불투명도 슬라이더. **원본 레이어**(기본 불투명도 0%, 기본 맨 위): 원본에선 지우개 = 원본을 100%로 드러내기, 복원 = 0%로 숨기기(슬라이더와 무관). 편집 레이어 선택: A / B / **A+B**(A와 B에 동시 적용, 원본은 그대로) / 원본 / **일괄**(지우면 A·B·원본 모두 0%). **마법봉** 선택(허용치/연속/샘플 기준, Shift 추가·Alt 빼기) + Delete로 선택 영역 지우기. **되돌리기**(Ctrl+Z, 30단계). **확대/축소**(버튼, Ctrl+휠, Space/휠 버튼 드래그 이동). **원본 블러**(0~100px, 실시간): 누끼(A·B) 모양은 선명한 원본, 나머지 원본만 흐리게 | 부분마다 A/B 중 원하는 쪽을 골라 `PNG 저장`(불투명도 반영) |
| 테두리 강조 | 레이어 편집기 현재 이미지 또는 외부 이미지를 가져와, 알파가 **임계값**(기본 128) 이상인 픽셀을 그림으로 보고 그림 바깥쪽 투명 영역에 **색상**(기본 검정)·**두께**(기본 1px) 테두리 픽셀 추가. 유클리드 거리 변환 기반이라 두께가 커도 모서리가 둥글고 빠름. 편집기에서 가져온 경우 **원본 레이어**를 결과 아래에 깔고 불투명도(기본 0%)·**블러**(누끼 모양 밖만 흐리게, 실시간) 조절 가능(테두리 인식에는 영향 없음) | 설정을 바꾸면 미리보기 즉시 갱신, 보이는 그대로 `PNG 저장` |

옵션 아래 **진행 로그** 창에 단계별 진행 상황과 소요 시간이 표시되고, A → B 순으로 끝나는 대로 결과가 바로 나타납니다.

## 설치

Python 3.10 이상.

```bash
pip install -r requirements.txt
```

> 첫 실행 시 rembg 모델(`isnet-anime` 약 176MB, `u2net` 약 170MB — u2net은 선택했을 때만)이 `~/.u2net/`에 자동 다운로드되므로 **네트워크가 필요**합니다.
> GPU를 쓰려면 `onnxruntime` 대신 `onnxruntime-gpu`를 설치하세요.

## 실행

**가장 간단한 방법**: 폴더의 `실행.bat`을 더블클릭 → 서버가 켜지고 준비되면 브라우저에서 http://127.0.0.1:7860 이 자동으로 열립니다.
- 콘솔 창을 닫으면 서버가 종료됩니다.
- 이미 실행 중이면 서버를 새로 띄우지 않고 페이지만 엽니다.
- Python이나 패키지가 없으면 안내 메시지를 보여주고 멈춥니다.

직접 실행:

```bash
python app.py
```

브라우저에서 http://127.0.0.1:7860 접속(주소 고정, 포트 7860이 사용 중이면 에러) → 이미지 업로드 → **분리 실행**.
화면은 기본적으로 **다크 테마**로 열립니다(주소에 `?__theme=dark`가 자동으로 붙음). 밝은 테마가 필요하면 페이지 하단 설정에서 라이트를 고르거나 `?__theme=light`로 접속하세요.
결과는 체크무늬 배경 위에 표시되며, 각 결과 아래에서 PNG를 다운로드할 수 있습니다(`outputs/`에도 저장).

## 폴더

- `methods/` — 방식별 함수 (`PIL.Image` 입력 → RGBA `PIL.Image` 출력)
- `layer_editor.py` — A/B 레이어 편집기 (브라우저 canvas)
- `test_images/` — 테스트 이미지
- `outputs/` — 마지막 실행 결과
