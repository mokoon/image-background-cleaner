# 캐릭터 배경 분리 비교 (char-cutout)

이미지 1장을 올리면 2가지 방식으로 배경을 제거해 투명 PNG 결과를 나란히 비교/다운로드하고, 레이어 편집기에서 부분별로 골라 합칠 수 있는 Gradio 앱.

옵션 아래 **진행 로그** 창에 단계별 진행 상황과 소요 시간이 표시되고, A → B 순으로 끝나는 대로 결과가 바로 나타납니다.

## 설치

Python 3.10 이상.

```bash
pip install -r requirements.txt
```

> 첫 실행 시 rembg 모델(`isnet-anime` 약 176MB, `u2net` 약 170MB — u2net은 선택했을 때만)이 `~/.u2net/`에 자동 다운로드되므로 **네트워크가 필요**합니다.
> GPU를 쓰려면 `onnxruntime` 대신 `onnxruntime-gpu`를 설치하세요.

## 실행

**가장 간단한 방법**: 폴더의 `실행.bat`을 더블클릭 → 서버가 켜지고 준비되면 브라우저에서 http://127.0.0.1:7860 이 자동으로 열립니다.
- 콘솔 창을 닫으면 서버가 종료됩니다.
- 이미 실행 중이면 서버를 새로 띄우지 않고 페이지만 엽니다.
- Python이나 패키지가 없으면 안내 메시지를 보여주고 멈춥니다.

직접 실행:

```bash
python app.py
```

브라우저에서 http://127.0.0.1:7860 접속(주소 고정, 포트 7860이 사용 중이면 에러) → 이미지 업로드 → **분리 실행**.
화면은 기본적으로 **다크 테마**로 열립니다(주소에 `?__theme=dark`가 자동으로 붙음). 밝은 테마가 필요하면 페이지 하단 설정에서 라이트를 고르거나 `?__theme=light`로 접속하세요.
결과는 체크무늬 배경 위에 표시되며, 각 결과 아래에서 PNG를 다운로드할 수 있습니다(`outputs/`에도 저장).

## 폴더

- `methods/` — 방식별 함수 (`PIL.Image` 입력 → RGBA `PIL.Image` 출력)
- `layer_editor.py` — A/B 레이어 편집기 (브라우저 canvas)
- `test_images/` — 테스트 이미지
- `outputs/` — 마지막 실행 결과
